## ⭐ Featured Projects

### ✈️ Flight Delay Prediction
Predicts whether a US flight will be on time or delayed (15+ / 30+ minutes), comparing classical ML against deep learning.

- Data cleaning, feature engineering and hyperparameter tuning (Random Forest, SVM, Gradient Boosting)
- Deep learning models in PyTorch (LSTM/GRU, MLP, Transformer) benchmarked against the ML baselines

**Stack:** `Python` · `Scikit-learn` · `PyTorch`
[→ View project](https://github.com/assiya-ouarradi/flight-delay-prediction)

### 🤖 Agentic RAG Pipeline
A RAG system where an agent decides whether to search the document collection or answer directly.

- PDF loading, chunking, embedding and storage in a vector database
- Query routing: retrieve from documents or respond without retrieval

**Stack:** `Python` · `LangChain` · `ChromaDB`
[→ View project](https://github.com/assiya-ouarradi/agentic-rag-pipeline)

### 🔎 AI Research Agent
An agent that searches the web, retrieves relevant passages, ranks them by similarity and returns concise summaries with sources.

- Web search and scraping, passage splitting
- Embedding-based ranking with cited sources

**Stack:** `Python` · `BeautifulSoup` · `Embeddings`
[→ View project](https://github.com/assiya-ouarradi/ai-research-agent)
